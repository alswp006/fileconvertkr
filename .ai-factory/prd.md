# FileConvertKR

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
아이폰 사진이 카톡에서 안 열려요? HEIC→JPG, PDF 합치기·압축 3초 변환

## Problem
아이폰 HEIC 사진을 카카오톡·이메일·회사 시스템에 올리면 열리지 않거나, PDF 용량이 커서 제출이 안 되는 문제를 거의 매주 겪는다. 웹 검색으로 찾은 무료 변환 사이트는 광고가 심하거나 원본 파일을 서버에 업로드해야 해 찜찜하다.

## Target Users
아이폰 사용 직장인·자영업자, 서류 제출이 잦은 20-40대

## Core Features
1. HEIC→JPG/PNG 즉시 변환
2. 이미지 용량 압축(목표 용량 지정)
3. PDF 여러 장 합치기
4. PDF→이미지 낱장 추출
5. PDF 파일 분할
6. 변환 이력 로컬 보관

## Monetization
- Model: ads
- Estimated MRR: 월 2,026원(출시 직후 DAU 15, 배너 노출 2회/일 기준)
- Reasoning: 변환 결과 화면 상하단에 배너 배치, 배치 변환(여러 파일 동시)·워터마크 제거는 리워드 광고 시청 후 해제하는 방식으로 마찰 없이 수익화. 외부 채널 유입 전까지는 기저선 DAU 15 가정, 공식 값 이상 근거 없음.
- Estimated DAU: 15
- Monthly Net Revenue (KRW): 2026
